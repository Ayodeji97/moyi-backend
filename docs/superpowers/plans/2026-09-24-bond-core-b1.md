# Slice B1 — The Bond and Its Guard: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A verified user can create a Bond (with its first invite code), list their Bonds and read one, and no non-member can learn that a Bond exists — with the guard, the Konsist rules and the cross-tenant suite that keep that true for every later endpoint.

**Architecture:** New `modules/bond` (`api/domain/service/infra/web`, own Flyway migration V9), an immutable `Bond` aggregate persisted through flat JPA entities and hand mappers, a `BondAccessGuard` that mints the `Membership` every bond-scoped service function requires, and identity's first `api` package (`UserDirectory`) as the cross-module port. Endpoints `POST /bonds`, `GET /bonds`, `GET /bonds/{bondId}`.

**Tech Stack:** Kotlin 2.4, Spring Boot 4.1 (Jackson 3, Spring Security resource server), Spring Data JPA / Hibernate 7, Flyway, Postgres 18 + Valkey via Testcontainers, kotest matchers, Konsist 0.17, springdoc, bash smoke script.

**Spec:** `docs/superpowers/specs/2026-09-24-bonds-and-invites-design.md` — sections 2, 3, 4, 5 (#1–#3), 6.1, 7 (V9), 8, 9 (B1), 10, 11.

## Global Constraints

- Every change is a PR from `feat/bond-core` (worktree `.worktrees/feat-bond-core`); never commit to `main`; never self-merge. Conventional Commits with the trailers below.
- Packages are `com.moyi.bond.<layer>` with `<layer>` ∈ `api, domain, infra, service, web`; everything outside `api` is `internal`; layers depend inwards (web → service/domain; service → domain/infra/api; infra → domain/api). `ArchitectureTest` in `app` enforces this.
- No cross-module JPA relationship and no foreign key across modules: `bond_members.user_id`, `bonds.created_by`, `blocks.*_user_id` are bare UUIDs.
- No personal data in logs or error `detail` (no email, no display name, no entry text). Log ids only.
- `Clock` and `IdGenerator` are injected; no `Instant.now()`; no `java.util.Date`.
- Detekt: functions ≤ 5 parameters, non-data-class constructors ≤ 6, `ThrowsCount` 3, `ReturnCount` 2, `MaxLineLength` 140, `MagicNumber` (name constants). ktlint official style.
- Bond name 1–60 chars trimmed; nickname ≤ 40; `MAX_OPEN_BONDS_PER_USER = 3`; invite TTL 7 days; alphabet `23456789ABCDEFGHJKMNPQRSTVWXYZ`, 6 characters.
- Timezones: region IANA ids only (in `ZoneId.getAvailableZoneIds()`, contain `/`, not `Etc/`, not `SystemV/`).
- Error contract: RFC 9457 with `code`; non-member or unknown or malformed bond id → `404 NOT_FOUND` detail "That bond was not found."; `403 EMAIL_NOT_VERIFIED`; `409 BOND_LIMIT_REACHED`; validation `422 VALIDATION_FAILED` with constraint-derived field codes.

```sql
-- Bond — doc 07 §2 "bond", ADR-0003 (a generic Bond, not a Couple), ADR-0026.
--
-- Owned by modules/bond (ADR-0014): the module's test context builds this
-- schema by itself. Versions are one global sequence across modules; V2–V8
-- are identity's. Forward-only: a mistake here is corrected by V10.
--
-- Deltas from doc 07 §2, each recorded in ADR-0026: `nickname_for_other`
-- (ADR-0003's rename), `created_by_member_id` (doc 04's name), and
-- `bonds.version` is the ETag (doc 06 §1). No foreign key points at
-- `users` — user ids cross the module boundary as bare UUIDs (doc 25 §6).

CREATE TABLE bonds (
    id                    uuid        PRIMARY KEY,
    -- Text plus CHECK rather than a Postgres enum, as every status column
    -- in this schema (see V2). FR-030: a new type is a wider CHECK, not a
    -- migration of data.
    type                  text        NOT NULL DEFAULT 'COUPLE',
    name                  text        NOT NULL,
    -- An IANA region id such as Africa/Lagos, validated in the domain
    -- (RegionZone). Never an offset: offsets change, zones do not (doc 04 §6).
    anchor_timezone       text        NOT NULL,
    timezone_changed_at   timestamptz,
    reveal_time_local     time,
    strict_mode           boolean     NOT NULL DEFAULT false,
    status                text        NOT NULL,
    -- On the row, not a constant: what makes FR-021 "a property of the Bond
    -- type" real rather than aspirational (doc 07 §2).
    max_members           smallint    NOT NULL DEFAULT 2,
    created_by            uuid        NOT NULL,
    created_at            timestamptz NOT NULL,
    archived_at           timestamptz,
    deletion_requested_at timestamptz,
    -- Optimistic concurrency for PATCH /bonds/{id} (If-Match, doc 06 §1).
    version               integer     NOT NULL DEFAULT 0,

    CONSTRAINT bonds_type_check CHECK (type IN ('COUPLE', 'FRIENDS', 'FAMILY', 'PARENT_CHILD')),
    CONSTRAINT bonds_status_check CHECK (status IN ('PENDING_MEMBER', 'ACTIVE', 'ARCHIVED', 'PENDING_DELETION', 'DELETED')),
    -- 60 is a number chosen in the Phase 2 spec (§5.2), not one FR-020 gives.
    CONSTRAINT bonds_name_length_check CHECK (char_length(name) BETWEEN 1 AND 60),
    CONSTRAINT bonds_anchor_timezone_length_check CHECK (char_length(anchor_timezone) BETWEEN 1 AND 64),
    CONSTRAINT bonds_max_members_check CHECK (max_members >= 2)
);

CREATE TABLE bond_members (
    id                  uuid        PRIMARY KEY,
    bond_id             uuid        NOT NULL REFERENCES bonds (id) ON DELETE CASCADE,
    user_id             uuid        NOT NULL,
    role                text        NOT NULL,
    joined_at           timestamptz NOT NULL,
    -- Set when the member leaves (FR-026). The row stays: the archive stays
    -- readable for the person who left (states.md §9, OQ-09).
    left_at             timestamptz,
    reminder_time_local time        NOT NULL DEFAULT '20:00',
    -- The MEMBER's zone, deliberately independent of the bond's anchor
    -- (doc 04 §6, the most misunderstood distinction in the system).
    reminder_timezone   text        NOT NULL,
    quiet_hours_start   time,
    quiet_hours_end     time,
    -- Unmapped until Phase 4; the default fills it.
    notification_prefs  jsonb       NOT NULL DEFAULT '{}',
    nickname_for_other  text,

    CONSTRAINT bond_members_role_check CHECK (role IN ('OWNER', 'MEMBER')),
    CONSTRAINT bond_members_reminder_timezone_length_check CHECK (char_length(reminder_timezone) BETWEEN 1 AND 64),
    CONSTRAINT bond_members_nickname_length_check
        CHECK (nickname_for_other IS NULL OR char_length(nickname_for_other) BETWEEN 1 AND 40)
);

-- One ACTIVE membership per user per bond (I-1's "same user twice" half). A
-- member who left and is invited back is a new row.
CREATE UNIQUE INDEX bond_members_active_key ON bond_members (bond_id, user_id) WHERE left_at IS NULL;
-- "My bonds" on every app open (doc 07 §4).
CREATE INDEX bond_members_user_id_active_idx ON bond_members (user_id) WHERE left_at IS NULL;
-- Loading a bond's members, and the guard's membership lookup.
CREATE INDEX bond_members_bond_id_idx ON bond_members (bond_id);

CREATE TABLE bond_invites (
    id                   uuid        PRIMARY KEY,
    bond_id              uuid        NOT NULL REFERENCES bonds (id) ON DELETE CASCADE,
    -- Six characters from the 30-symbol alphabet states.md §2 fixed; the
    -- CHECK is the alphabet, so a code outside it cannot be stored by any
    -- path (T-06).
    code                 text        NOT NULL,
    created_by_member_id uuid        NOT NULL REFERENCES bond_members (id) ON DELETE CASCADE,
    expires_at           timestamptz NOT NULL,
    used_at              timestamptz,
    used_by_user_id      uuid,
    revoked_at           timestamptz,

    -- Unique across every invite ever issued, live or not: the code space is
    -- 7.3e8 and the table stays small, so a collision is a 500 for one request
    -- and a fresh code for the next (ADR-0026).
    CONSTRAINT bond_invites_code_key UNIQUE (code),
    CONSTRAINT bond_invites_code_shape_check CHECK (code ~ '^[23456789ABCDEFGHJKMNPQRSTVWXYZ]{6}$')
);

-- The lookup on accept and resolve (B2): only live codes matter.
CREATE INDEX bond_invites_live_code_idx ON bond_invites (code) WHERE used_at IS NULL AND revoked_at IS NULL;
CREATE INDEX bond_invites_bond_id_idx ON bond_invites (bond_id);

-- FR-029. Written by B3, checked by B2's accept in both directions.
CREATE TABLE blocks (
    id              uuid        PRIMARY KEY,
    blocker_user_id uuid        NOT NULL,
    blocked_user_id uuid        NOT NULL,
    bond_id         uuid        NOT NULL REFERENCES bonds (id) ON DELETE CASCADE,
    created_at      timestamptz NOT NULL,

    -- FR-025 permits three bonds and nothing stops the same two people
    -- sharing two of them (doc 07 §2), so the bond is part of the key.
    CONSTRAINT blocks_pair_bond_key UNIQUE (blocker_user_id, blocked_user_id, bond_id),
    CONSTRAINT blocks_not_self_check CHECK (blocker_user_id <> blocked_user_id)
);

CREATE INDEX blocks_blocked_user_id_idx ON blocks (blocked_user_id);
CREATE INDEX blocks_blocker_user_id_idx ON blocks (blocker_user_id);
```

`RegionZone.kt`:
```kotlin
package com.moyi.bond.domain

import java.time.ZoneId

/**
 * An IANA *region* time zone — `Africa/Lagos`, never `UTC`, `GMT+3` or
 * `Etc/GMT-1` — for a bond's anchor (ADR-0004) and a member's reminders
 * (doc 04 §6). Doc 04 §6: store the zone id as text and never an offset,
 * because offsets change with the calendar and zones do not. Fixed-offset
 * ids are refused for the same reason: they carry no DST rules and would
 * make "our day" drift twice a year for a couple who chose one by mistake.
 *
 * Deprecated aliases (`Asia/Calcutta`) are accepted and stored as given —
 * the JDK resolves them, and rewriting what a person chose is not this
 * type's job.
 */
@JvmInline
internal value class RegionZone(
    val zone: ZoneId,
) {
    val id: String get() = zone.id

    companion object {
        /** @throws IllegalArgumentException with the sentence a user reads, which never echoes the input. */
        fun of(id: String): RegionZone {
            require(id.isRegionZoneId()) { "must be a region time zone such as Europe/London or Africa/Lagos" }
            return RegionZone(ZoneId.of(id))
        }

        private fun String.isRegionZoneId(): Boolean =
            this in ZoneId.getAvailableZoneIds() &&
                contains('/') &&
                !startsWith("Etc/") &&
                !startsWith("SystemV/")
    }
}
```

`InviteCode.kt`:
```kotlin
package com.moyi.bond.domain

import java.util.Random

/**
 * A six-character invite code (FR-022) from the alphabet `states.md` §2
 * fixed on 2026-09-03: no `0`/`O`, no `1`/`I`/`L` — the pairs people
 * mis-transcribe when reading a code aloud down a phone line, which is how a
 * long-distance couple shares one — and no `U`, so six random characters
 * cannot spell something unfortunate. 30⁶ ≈ 7.3 × 10⁸ codes, ~29.4 bits;
 * doc 09 T-06's "32 symbols" is the stale number (ADR-0026 amends it). The
 * rate limits in doc 06 §4 are what make that space enough (B2).
 *
 * Always upper case inside the system. The database CHECK in V9 restates
 * the alphabet, so a code outside it cannot be stored by any path.
 */
@JvmInline
internal value class InviteCode(
    val value: String,
) {
    init {
        require(value.length == LENGTH) { "must be $LENGTH characters" }
        require(value.all { it in ALPHABET }) { "may only use the digits 2 to 9 and letters A to Z, never 0, O, 1, I, L or U" }
    }

    companion object {
        const val LENGTH = 6
        const val ALPHABET = "23456789ABCDEFGHJKMNPQRSTVWXYZ"

        /**
         * Normalises what a person typed — trimmed, upper-cased — and refuses
         * anything else with the domain's own sentence. A code entry field
         * capitalises automatically (`states.md` §2), but a pasted lowercase
         * link must work too.
         */
        fun parse(raw: String): InviteCode = InviteCode(raw.trim().uppercase())

        /**
         * Six uniformly chosen symbols. [random] is a parameter so production
         * passes a `SecureRandom` and a test passes a seeded one and can name
         * the code it expects — the same reason `IdGenerator` is a port.
         */
        fun random(random: Random): InviteCode = InviteCode(String(CharArray(LENGTH) { ALPHABET[random.nextInt(ALPHABET.length)] }))
    }
}

/** The port that hands out codes; `infra.security.SecureInviteCodes` is the adapter. */
internal fun interface InviteCodes {
    fun next(): InviteCode
}
```

```kotlin
package com.moyi.bond.domain

import java.time.Instant
import java.time.LocalTime

/**
 * FR-030: the type is a discriminator, and `maxMembers` hangs off it so a new
 * type is a new enum constant, never a migration. Every type is two people
 * in v1; the number is here rather than a constant so that changing it for
 * one type is a one-line change (FR-021).
 */
internal enum class BondType(
    val maxMembers: Int,
) {
    COUPLE(2),
    FRIENDS(2),
    FAMILY(2),
    PARENT_CHILD(2),
}

/** Doc 04 §4.3. Transitions are methods on [Bond]; B1 only creates. */
internal enum class BondStatus { PENDING_MEMBER, ACTIVE, ARCHIVED, PENDING_DELETION, DELETED }

/** What `POST /bonds` asks for (spec §5.2 #1), already validated at the edge. */
internal data class BondDraft(
    val creator: UserId,
    val type: BondType,
    val name: String,
    val anchorTimezone: RegionZone,
    val revealTimeLocal: LocalTime?,
    /** The creator's own zone for reminders; `null` means "the anchor, until they set one" (spec §11 decision 11). */
    val reminderTimezone: RegionZone?,
)

/**
 * The aggregate root (ADR-0003): a relationship between a small number of
 * people, generic over its type. Immutable; a state change is a method
 * returning a new `Bond` (the `User` precedent). The invariants doc 04 §2
 * assigns to the aggregate are `require`d here, so an object that violates
 * one cannot exist in memory:
 *
 * - I-1 `activeMembers.size <= maxMembers`, and one active membership per user.
 * - I-5 an archived bond accepts no writes — enforced by the transition
 *   methods that arrive in B3–B5; B1 has none.
 *
 * `members` includes people who have left: they keep read access to the
 * archive (`states.md` §9, OQ-09), so "is this user a member" has to be
 * answerable for them. [activeMembers] is the current pair.
 */
internal data class Bond(
    val id: BondId,
    val type: BondType,
    val name: String,
    val anchorTimezone: RegionZone,
    val timezoneChangedAt: Instant?,
    val revealTimeLocal: LocalTime?,
    val strictMode: Boolean,
    val status: BondStatus,
    val maxMembers: Int,
    val createdBy: UserId,
    val createdAt: Instant,
    val archivedAt: Instant?,
    val deletionRequestedAt: Instant?,
    /** The row version behind the ETag (doc 06 §1). `0` until the first update. */
    val version: Int,
    val members: List<Member>,
) {
    init {
        // Mirrors V9's CHECKs; both exist on purpose — the database one cannot
        // be bypassed, this one fails in the layer that can explain itself.
        require(name.isNotBlank() && name.trim() == name && name.length <= MAX_NAME_LENGTH) {
            "a bond name must be between 1 and $MAX_NAME_LENGTH characters"
        }
        require(maxMembers >= MIN_MEMBERS) { "a bond has at least $MIN_MEMBERS seats" }
        require(members.all { it.bondId == id }) { "every member row must belong to this bond" }
        require(activeMembers.size <= maxMembers) { "a bond has at most $maxMembers active members (I-1)" }
        require(activeMembers.distinctBy { it.userId }.size == activeMembers.size) {
            "a user holds at most one active membership in a bond"
        }
    }

    val activeMembers: List<Member> get() = members.filter(Member::isActive)

    /** The user's membership, current or left; `null` for a stranger. */
    fun memberOf(userId: UserId): Member? = members.firstOrNull { it.userId == userId }

    companion object {
        /** Spec §5.2: chosen there, not in FR-020. Flagged for Daniel. */
        const val MAX_NAME_LENGTH = 60
        const val MIN_MEMBERS = 2

        /** FR-025: the v1 abuse control. Counts `PENDING_MEMBER` and `ACTIVE` bonds the user has not left. */
        const val MAX_OPEN_BONDS_PER_USER = 3

        /** A bond with its creator as `OWNER`, waiting for its second member (doc 04 §4.3). */
        fun create(
            id: BondId,
            ownerMemberId: MemberId,
            draft: BondDraft,
            now: Instant,
        ): Bond {
            val owner =
                Member.join(
                    id = ownerMemberId,
                    bondId = id,
                    userId = draft.creator,
                    role = MemberRole.OWNER,
                    reminderTimezone = draft.reminderTimezone ?: draft.anchorTimezone,
                    now = now,
                )
            return Bond(
                id = id,
                type = draft.type,
                name = draft.name,
                anchorTimezone = draft.anchorTimezone,
                timezoneChangedAt = null,
                revealTimeLocal = draft.revealTimeLocal,
                strictMode = false,
                status = BondStatus.PENDING_MEMBER,
                maxMembers = draft.type.maxMembers,
                createdBy = draft.creator,
                createdAt = now,
                archivedAt = null,
                deletionRequestedAt = null,
                version = 0,
                members = listOf(owner),
            )
        }
    }
}
```

```kotlin
package com.moyi.identity.api

import java.util.UUID

/**
 * What another module may know about a user (ADR-0026): enough to say
 * "verified?" and to print a name next to an entry, and nothing else — no
 * email, no status, no timestamps. The `bond` module asks this before
 * creating or joining (FR-002) and when rendering members.
 *
 * The first `api` package in a domain module, and the pattern for every
 * later one: an interface plus plain DTOs, public, depending on nothing;
 * the implementation stays `internal` in `service`. A caller depends on the
 * module and reaches only this (the `notification.api.EmailSender`
 * precedent). Cross-module calls are in-process method calls in a modular
 * monolith (ADR-0001); the boundary is the *visibility*, not the transport.
 */
interface UserDirectory {
    /** `null` for an id that names nobody. */
    fun find(id: UUID): UserSummary?

    /** The subset of [ids] that exist, keyed by id. */
    fun findAll(ids: Collection<UUID>): Map<UUID, UserSummary>
}

/** A user as seen from outside identity. `toString` prints only the id: a display name is personal data (doc 18 §9). */
data class UserSummary(
    val id: UUID,
    val displayName: String,
    val emailVerified: Boolean,
) {
    override fun toString(): String = "UserSummary(id=$id)"
}
```

```kotlin
package com.moyi.bond.infra

import com.moyi.identity.api.UserDirectory
import com.moyi.identity.api.UserSummary
import java.util.UUID
import java.util.concurrent.ConcurrentHashMap

/**
 * The identity port, in memory. The bond module's test context does not
 * boot identity (see [BondTestApplication]); what it needs of a user is what
 * the port says, and this is the port. The real adapter is tested in
 * identity (`AccountDirectoryTest`) and wired in `app`.
 */
internal class FakeUserDirectory : UserDirectory {
    private val users = ConcurrentHashMap<UUID, UserSummary>()

    fun verified(displayName: String): UUID = add(displayName, verified = true)

    fun unverified(displayName: String): UUID = add(displayName, verified = false)

    fun clear() = users.clear()

    override fun find(id: UUID): UserSummary? = users[id]

    override fun findAll(ids: Collection<UUID>): Map<UUID, UserSummary> = ids.mapNotNull { users[it] }.associateBy { it.id }

    private fun add(
        displayName: String,
        verified: Boolean,
    ): UUID {
        val id = UUID.randomUUID()
        users[id] = UserSummary(id, displayName, verified)
        return id
    }
}
```

```kotlin
/**
 * Real Postgres, real Flyway, real Hibernate: the constraints in V9, the
 * statements Hibernate emits, and whether the mapping agrees with the
 * schema (`ddl-auto: validate` — the context does not start otherwise).

@SpringBootTest(classes = [BondTestApplication::class])
internal class BondPersistenceTest(
    @Autowired private val store: BondStore,
    @Autowired private val transactions: TransactionTemplate,
    @Autowired entityManagerFactory: EntityManagerFactory,
    @Autowired dataSource: DataSource,
) : IntegrationTest() {
    private val statistics = entityManagerFactory.unwrap(SessionFactory::class.java).statistics
    private val jdbc = JdbcTemplate(dataSource)
    private val ids = DeterministicIdGenerator()
    private val now = Instant.parse("2026-09-24T20:00:00Z")
    private val lagos = RegionZone.of("Africa/Lagos")

    @AfterEach
    fun clear() {
        jdbc.execute("TRUNCATE TABLE blocks, bond_invites, bond_members, bonds CASCADE")
    }

    private fun newBond(
        creator: UserId = UserId(UUID.randomUUID()),
        createdAt: Instant = now,
    ): Pair<Bond, Invite> {
        val draft = BondDraft(creator, BondType.COUPLE, "Us", lagos, null, null)
        val bond = Bond.create(BondId(ids.timeOrdered()), MemberId(ids.timeOrdered()), draft, createdAt)
        val invite = Invite.issue(InviteId(ids.timeOrdered()), bond.id, InviteCode.random(Random(bond.id.hashCode().toLong())), bond.members.single().id, createdAt)
        return bond to invite
    }

    @Test
    fun `inserting a bond with assigned ids costs one INSERT per row, no SELECT`() {
        // The Persistable reason, as in UserPersistenceTest: without it every
        // insert pays a SELECT for a row that cannot exist.
        val (bond, invite) = newBond()
        statistics.clear()

        transactions.executeWithoutResult { store.insert(bond, invite) }

        statistics.entityInsertCount shouldBe 3
        statistics.entityLoadCount shouldBe 0
        statistics.prepareStatementCount shouldBe 3
    }

    @Test
    fun `a bond round-trips through the mapper for a member, and is invisible to a stranger`() {
        val (bond, invite) = newBond()
        transactions.executeWithoutResult { store.insert(bond, invite) }

        val loaded = transactions.execute { store.findByMember(bond.id, bond.createdBy) }
        loaded shouldBe bond

        transactions.execute { store.findByMember(bond.id, UserId(UUID.randomUUID())) }.shouldBeNull()
        transactions.execute { store.findByMember(BondId(UUID.randomUUID()), bond.createdBy) }.shouldBeNull()
    }

    @Test
    fun `a member who left still finds the bond`() {
        val (bond, invite) = newBond()
        transactions.executeWithoutResult { store.insert(bond, invite) }
        jdbc.update("UPDATE bond_members SET left_at = now() WHERE bond_id = ?", bond.id.value)

        transactions.execute { store.findByMember(bond.id, bond.createdBy) }.shouldNotBeNull().activeMembers shouldBe emptyList()
    }

    @Test
    fun `my bonds are every bond I hold a membership row in, newest first`() {
        val me = UserId(UUID.randomUUID())
        val (older, olderInvite) = newBond(creator = me, createdAt = now.minus(Duration.ofDays(1)))
        val (newer, newerInvite) = newBond(creator = me)
        val (theirs, theirsInvite) = newBond()
        transactions.executeWithoutResult {
            store.insert(older, olderInvite)
            store.insert(newer, newerInvite)
            store.insert(theirs, theirsInvite)
        }

        transactions.execute { store.findAllByMember(me) }!!.map { it.id } shouldContainExactly listOf(newer.id, older.id)
    }

    @Test
    fun `open bonds are PENDING_MEMBER or ACTIVE ones I have not left`() {
        val me = UserId(UUID.randomUUID())
        val (a, ai) = newBond(creator = me)
        val (b, bi) = newBond(creator = me)
        val (c, ci) = newBond(creator = me)
        transactions.executeWithoutResult {
            store.insert(a, ai)
            store.insert(b, bi)
            store.insert(c, ci)
        }
        transactions.execute { store.countOpenBondsOf(me) } shouldBe 3

        jdbc.update("UPDATE bonds SET status = 'ARCHIVED', archived_at = now() WHERE id = ?", a.id.value)
        jdbc.update("UPDATE bond_members SET left_at = now() WHERE bond_id = ?", b.id.value)

        transactions.execute { store.countOpenBondsOf(me) } shouldBe 1
    }

    @Test
    fun `live invites are keyed by bond and exclude used, revoked and expired ones`() {
        val (a, ai) = newBond()
        val (b, bi) = newBond()
        transactions.executeWithoutResult {
            store.insert(a, ai)
            store.insert(b, bi)
        }
        jdbc.update("UPDATE bond_invites SET revoked_at = now() WHERE id = ?", bi.id.value)

        val live = transactions.execute { store.findLiveInvites(listOf(a.id, b.id), now) }!!
        live shouldHaveSize 1
        live[a.id] shouldBe ai
        transactions.execute { store.findLiveInvites(listOf(a.id), now.plus(Duration.ofDays(8))) }!! shouldHaveSize 0
    }

    @Test
    fun `V9's constraints hold - one active membership per user, unique codes, name length`() {
        val (bond, invite) = newBond()
        transactions.executeWithoutResult { store.insert(bond, invite) }

        shouldThrow<DataIntegrityViolationException> {
            jdbc.update(
                "INSERT INTO bond_members (id, bond_id, user_id, role, joined_at, reminder_timezone) VALUES (?, ?, ?, 'MEMBER', now(), 'Africa/Lagos')",
                UUID.randomUUID(),
                bond.id.value,
                bond.createdBy.value,
            )
        }.message!!.contains("bond_members_active_key") shouldBe true

        shouldThrow<DataIntegrityViolationException> {
            jdbc.update(
                "INSERT INTO bond_invites (id, bond_id, code, created_by_member_id, expires_at) VALUES (?, ?, ?, ?, now())",
                UUID.randomUUID(),
                bond.id.value,
                invite.code.value,
                bond.members.single().id.value,

        }.message!!.contains("bond_invites_code_key") shouldBe true

        shouldThrow<DataIntegrityViolationException> {
            jdbc.update("UPDATE bonds SET name = ? WHERE id = ?", "x".repeat(61), bond.id.value)
        }.message!!.contains("bonds_name_length_check") shouldBe true
    }
}
```

```kotlin
package com.moyi.bond.infra.database

import com.moyi.bond.domain.BondStatus
import com.moyi.bond.domain.BondType
import jakarta.persistence.Column
import jakarta.persistence.Entity
import jakarta.persistence.EnumType
import jakarta.persistence.Enumerated
import jakarta.persistence.Id
import jakarta.persistence.PostLoad
import jakarta.persistence.PostPersist
import jakarta.persistence.Table
import jakarta.persistence.Transient
import jakarta.persistence.Version
import org.springframework.data.domain.Persistable
import java.time.Instant
import java.time.LocalTime
import java.util.UUID

/**
 * The `bonds` row. A persistence detail (the `UserEntity` precedent, whose
 * KDoc explains [Persistable] and why this is not a `data class`).
 *
 * `@Version` on `version`: Hibernate adds `WHERE version = ?` to every
 * UPDATE and bumps it, which is what makes `If-Match` (B4) a real check
 * rather than a comparison the application performs and then forgets to
 * honour under concurrency. `maxMembers` is `Short` because the column is
 * `smallint`; `ddl-auto: validate` refuses an `Int` against it.
 */
@Entity
@Table(name = "bonds")
internal class BondEntity(
    @Id
    @Column(name = "id", nullable = false, updatable = false)
    private val id: UUID,
    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    var type: BondType,
    @Column(nullable = false)
    var name: String,
    @Column(nullable = false)
    var anchorTimezone: String,
    var timezoneChangedAt: Instant?,
    var revealTimeLocal: LocalTime?,
    @Column(nullable = false)
    var strictMode: Boolean,
    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    var status: BondStatus,
    @Column(nullable = false)
    var maxMembers: Short,
    @Column(nullable = false, updatable = false)
    var createdBy: UUID,
    @Column(nullable = false, updatable = false)
    var createdAt: Instant,
    var archivedAt: Instant?,
    var deletionRequestedAt: Instant?,
    @Version
    @Column(nullable = false)
    var version: Int,
) : Persistable<UUID> {
    @Transient
    private var new: Boolean = true

    override fun getId(): UUID = id

    override fun isNew(): Boolean = new

    @PostPersist
    @PostLoad
    private fun markNotNew() {
        new = false
    }

    override fun equals(other: Any?): Boolean = this === other || (other is BondEntity && id == other.id)

    override fun hashCode(): Int = id.hashCode()

    override fun toString(): String = "BondEntity(id=$id, status=$status)"
}
```

```kotlin
package com.moyi.bond.infra.database

import com.moyi.bond.domain.BondStatus
import org.springframework.data.jpa.repository.Query
import org.springframework.data.repository.Repository
import java.time.Instant
import java.util.UUID

/**
 * On Spring Data's bare [Repository] marker (the `CredentialsRepository`
 * precedent): what a repository *cannot* do is part of its design. There is
 * no `findAll()` over every bond in the system, and — doc 05 §5.5 layer 3 —
 * no method here returns bond-scoped data without a bond id or a user id in
 * its predicate. [BondStore] is the only caller.
 */
internal interface BondRepository : Repository<BondEntity, UUID> {
    fun save(bond: BondEntity): BondEntity

    fun findById(id: UUID): BondEntity?

    fun findAllByIdIn(ids: Collection<UUID>): List<BondEntity>

    /**
     * Serialises "count my open bonds, then create one" for a user for the
     * rest of the transaction, so two concurrent creates cannot both see two
     * and both make a fourth (FR-025). Transaction-scoped advisory lock, the
     * `RefreshTokenRepository.lockSessions` precedent; namespace `2` so it
     * cannot collide with identity's sessions lock (`1`).
     */
    @Query(nativeQuery = true, value = "SELECT 1 FROM (SELECT pg_advisory_xact_lock(2, hashtext(CAST(:userId AS text)))) AS held")
    fun lockBondsOf(userId: UUID): Int
}

internal interface BondMemberRepository : Repository<BondMemberEntity, UUID> {
    fun saveAll(members: Iterable<BondMemberEntity>): List<BondMemberEntity>

    fun findAllByBondId(bondId: UUID): List<BondMemberEntity>

    fun findAllByBondIdIn(bondIds: Collection<UUID>): List<BondMemberEntity>

    fun findAllByUserId(userId: UUID): List<BondMemberEntity>

    /** FR-025's count: memberships not left, in bonds whose status is in [statuses]. */
    @Query(
        """
        SELECT COUNT(m) FROM BondMemberEntity m, BondEntity b
         WHERE b.id = m.bondId
           AND m.userId = :userId
           AND m.leftAt IS NULL
           AND b.status IN :statuses
        """,
    )
    fun countByUserIdAndBondStatusIn(
        userId: UUID,
        statuses: Collection<BondStatus>,
    ): Long
}

internal interface BondInviteRepository : Repository<BondInviteEntity, UUID> {
    fun save(invite: BondInviteEntity): BondInviteEntity

    /** The live invite of each listed bond — at most one per bond once B2 enforces the rule. */
    @Query(
        """
        SELECT i FROM BondInviteEntity i
         WHERE i.bondId IN :bondIds
           AND i.usedAt IS NULL
           AND i.revokedAt IS NULL
           AND i.expiresAt > :now
        """,
    )
    fun findAllLiveByBondIdIn(
        bondIds: Collection<UUID>,
        now: Instant,
    ): List<BondInviteEntity>
}
```

```kotlin
package com.moyi.bond.infra.database

import com.moyi.bond.domain.Bond
import com.moyi.bond.domain.BondId
import com.moyi.bond.domain.Invite
import com.moyi.bond.domain.InviteCode
import com.moyi.bond.domain.InviteId
import com.moyi.bond.domain.Member
import com.moyi.bond.domain.MemberId
import com.moyi.bond.domain.RegionZone
import com.moyi.bond.domain.UserId

/**
 * Domain ↔ persistence, by hand (the `IdentityMappers` precedent: MapStruct
 * does not see value classes, and a reflective mapper turns a rename into a
 * runtime surprise). [toEntity] is insert-only; updates arrive with B3 as
 * `applyTo` functions.
 *
 * `RegionZone.of` on the way *out* of the database re-validates the stored
 * id: a zone the JDK's tzdb has dropped would fail here, loudly, rather than
 * silently filing a day under the wrong date.
 */
internal fun BondEntity.toDomain(members: List<BondMemberEntity>): Bond =
    Bond(
        id = BondId(getId()),
        type = type,
        name = name,
        anchorTimezone = RegionZone.of(anchorTimezone),
        timezoneChangedAt = timezoneChangedAt,
        revealTimeLocal = revealTimeLocal,
        strictMode = strictMode,
        status = status,
        maxMembers = maxMembers.toInt(),
        createdBy = UserId(createdBy),
        createdAt = createdAt,
        archivedAt = archivedAt,
        deletionRequestedAt = deletionRequestedAt,
        version = version,
        members = members.map { it.toDomain() }.sortedBy { it.joinedAt },
    )

internal fun Bond.toEntity(): BondEntity =
    BondEntity(
        id = id.value,
        type = type,
        name = name,
        anchorTimezone = anchorTimezone.id,
        timezoneChangedAt = timezoneChangedAt,
        revealTimeLocal = revealTimeLocal,
        strictMode = strictMode,
        status = status,
        maxMembers = maxMembers.toShort(),
        createdBy = createdBy.value,
        createdAt = createdAt,
        archivedAt = archivedAt,
        deletionRequestedAt = deletionRequestedAt,
        version = version,
    )

internal fun BondMemberEntity.toDomain(): Member =
    Member(
        id = MemberId(getId()),
        bondId = BondId(bondId),
        userId = UserId(userId),
        role = role,
        joinedAt = joinedAt,
        leftAt = leftAt,
        reminderTimeLocal = reminderTimeLocal,
        reminderTimezone = RegionZone.of(reminderTimezone),
        quietHoursStart = quietHoursStart,
        quietHoursEnd = quietHoursEnd,
        nicknameForOther = nicknameForOther,
    )

internal fun Member.toEntity(): BondMemberEntity =
    BondMemberEntity(
        id = id.value,
        bondId = bondId.value,
        userId = userId.value,
        role = role,
        joinedAt = joinedAt,
        leftAt = leftAt,
        reminderTimeLocal = reminderTimeLocal,
        reminderTimezone = reminderTimezone.id,
        quietHoursStart = quietHoursStart,
        quietHoursEnd = quietHoursEnd,
        nicknameForOther = nicknameForOther,
    )

internal fun BondInviteEntity.toDomain(): Invite =
    Invite(
        id = InviteId(getId()),
        bondId = BondId(bondId),
        code = InviteCode(code),
        createdByMemberId = MemberId(createdByMemberId),
```

```kotlin
package com.moyi.bond.infra.database

import com.moyi.bond.domain.Bond
import com.moyi.bond.domain.BondId
import com.moyi.bond.domain.BondStatus
import com.moyi.bond.domain.Invite
import com.moyi.bond.domain.UserId
import org.springframework.stereotype.Component
import java.time.Instant

/**
 * The Bond aggregate, spoken in domain terms (the `AccountStore` precedent).
 * Loads a bond *with* its members in two statements and hands back one
 * object; the service never sees a repository or an entity.
 *
 * **Every read is scoped to a user** (doc 05 §5.5 layer 3): there is no
 * `find(bondId)`. A caller who cannot say who is asking cannot ask, which is
 * the repository-level half of T-02's defence. Not transactional itself —
 * the boundary is the caller's (doc 18 §4).
 */
@Component
internal class BondStore(
    private val bonds: BondRepository,
    private val members: BondMemberRepository,
    private val invites: BondInviteRepository,
) {
    /** The bond, its member rows and its first invite — one aggregate, three tables. */
    fun insert(
        bond: Bond,
        invite: Invite,
    ) {
        bonds.save(bond.toEntity())
        members.saveAll(bond.members.map { it.toEntity() })
        invites.save(invite.toEntity())
    }

    /**
     * The bond if [userId] holds a membership row in it — current or left —
     * and `null` otherwise, which the guard turns into the 404 that does not
     * confirm the id exists. The member rows are read first because they are
     * the authorisation; the bond row is read only once it is known to be
     * the caller's to see.
     */
    fun findByMember(
        bondId: BondId,
        userId: UserId,
    ): Bond? {
        val rows = members.findAllByBondId(bondId.value)
        if (rows.none { it.userId == userId.value }) return null
        return bonds.findById(bondId.value)?.toDomain(rows)
    }

    /** Every bond the user has a membership row in, newest first (`GET /bonds`). */
    fun findAllByMember(userId: UserId): List<Bond> {
        val mine = members.findAllByUserId(userId.value).map { it.bondId }.distinct()
        if (mine.isEmpty()) return emptyList()
        val rows = members.findAllByBondIdIn(mine).groupBy { it.bondId }
        return bonds
            .findAllByIdIn(mine)
            .map { it.toDomain(rows[it.getId()].orEmpty()) }
            .sortedByDescending { it.createdAt }
    }

    /** Must precede [countOpenBondsOf] in the transaction that creates or joins. */
    fun lockBondsOf(userId: UserId) {
        bonds.lockBondsOf(userId.value)
    }

    fun countOpenBondsOf(userId: UserId): Int = members.countByUserIdAndBondStatusIn(userId.value, OPEN_STATUSES).toInt()

    fun findLiveInvites(
        bondIds: Collection<BondId>,
        now: Instant,
    ): Map<BondId, Invite> =
        invites
            .findAllLiveByBondIdIn(bondIds.map { it.value }, now)
            .map { it.toDomain() }
            .associateBy { it.bondId }

    private companion object {
        /** FR-025 counts a bond that is waiting for its partner as much as one that has them. */
        val OPEN_STATUSES = listOf(BondStatus.PENDING_MEMBER, BondStatus.ACTIVE)
    }
}
```

```kotlin
package com.moyi.bond.service

import com.moyi.bond.domain.Bond
import com.moyi.bond.domain.BondDraft
import com.moyi.bond.infra.database.BondStore
import com.moyi.identity.api.UserDirectory
import org.slf4j.LoggerFactory
import org.springframework.stereotype.Service
import org.springframework.transaction.annotation.Transactional

/**
 * `POST /bonds` (FR-020): a verified user's new bond, waiting for its
 * second member, with the invite that will bring them (doc 06 §3.3).
 *
 * The FR-025 count runs under a per-user advisory lock so two concurrent
 * creates cannot both pass it. Checked *after* verification, because the
 * lock is a cost and an unverified caller should pay nothing.
 */
@Service
internal class CreateBond(
    private val users: UserDirectory,
    private val bonds: BondStore,
    private val factory: BondFactory,
    private val views: BondViews,
) {
    private val log = LoggerFactory.getLogger(javaClass)

    /**
     * @throws EmailNotVerifiedException the caller has not verified their address (FR-002), or no longer exists
     * @throws BondLimitReachedException the caller already has three open bonds (FR-025)
     */
    @Transactional
    fun create(draft: BondDraft): BondView {
        val creator = users.find(draft.creator.value)
        if (creator == null || !creator.emailVerified) throw EmailNotVerifiedException()
        bonds.lockBondsOf(draft.creator)
        if (bonds.countOpenBondsOf(draft.creator) >= Bond.MAX_OPEN_BONDS_PER_USER) throw BondLimitReachedException()

        val (bond, invite) = factory.create(draft)
        bonds.insert(bond, invite)
        // Ids only: the name is the couple's, and the code is a credential.
        log.info("Bond {} created by user {}", bond.id.value, draft.creator.value)
        return views.of(bond, draft.creator)
    }
}
```

```kotlin
    override fun isValid(

        return validate(context) { RegionZone.of(value.trim()) }
    }
```

```kotlin
import com.moyi.bond.domain.BondId
import com.moyi.bond.domain.Membership

/**
 * Doc 05 §5.5 layer 2, doc 09 §4: **the** place a caller's membership in a
 * bond is decided. Every bond-scoped controller calls this first and hands
 * the [Membership] it returns to the service; every bond-scoped service
 * function takes a `Membership`, never a `BondId` (Konsist holds both halves
 * in `ArchitectureTest`).
 *
 * A non-member, an unknown id and a malformed id are one answer — 404, "not
 * found or not permitted to know it exists" (doc 06 §2) — because a 403
 * would confirm the bond exists (T-02). A member who **left** gets a
 * membership marked `left`: they may read the archive (`states.md` §9) and
 * every write path refuses them.
 *
 * This is the only file that constructs a `Membership`. That is what makes
 * the type a proof rather than a data class.
 */
@Service
internal class BondAccessGuard(
    private val bonds: BondStore,
) {
    /** @throws BondNotFoundException the caller holds no membership row in [bondId], or there is no such bond */
    @Transactional(readOnly = true)
    fun membershipOf(
        caller: UserId,
        bondId: BondId,
    ): Membership {
        val bond = bonds.findByMember(bondId, caller) ?: throw BondNotFoundException()
        val member = bond.memberOf(caller) ?: throw BondNotFoundException()
        return Membership(
            bondId = bond.id,
            memberId = member.id,
            userId = member.userId,
            role = member.role,
            left = !member.isActive,
        )
    }
}

/** One answer for "not yours", "not real" and "not an id" (doc 06 §2). The catch-all writes the 404. */
internal class BondNotFoundException : NotFoundException("That bond was not found.")
```

```kotlin
import com.moyi.bond.domain.UserId
import com.moyi.bond.service.BondAccessGuard
import com.moyi.bond.service.BondNotFoundException
import com.moyi.bond.service.CreateBond
import com.moyi.bond.service.GetBond
import com.moyi.bond.service.ListBonds
import com.moyi.common.security.CurrentUser
import jakarta.validation.Valid
import org.springframework.http.HttpStatus
import org.springframework.http.ResponseEntity
import org.springframework.web.bind.annotation.GetMapping
import org.springframework.web.bind.annotation.PathVariable
import org.springframework.web.bind.annotation.PostMapping
import org.springframework.web.bind.annotation.RequestBody
import org.springframework.web.bind.annotation.RequestMapping

/**
 * `/api/v1/bonds` (doc 06 §3.3). Behind the bearer; nothing here does any
 * work (doc 18 §4). Every response that carries a bond carries its `ETag`,
 * so a client that later PATCHes (B4) already has the `If-Match` it needs.
 *
 * A bond-scoped method's first statement is the guard, before any body is
 * validated or any state examined, so a non-member never sees a 422, 412 or
 * 409 that a member would. The id is taken as text and parsed here: a value
 * that is not a UUID cannot name a bond, and the answer is the same 404
 * (the `SessionsController` precedent).
 */
@RestController
@RequestMapping("/api/v1/bonds")
internal class BondsController(
    private val guard: BondAccessGuard,
    private val createBond: CreateBond,
    private val getBond: GetBond,
    private val listBonds: ListBonds,
) {
    @PostMapping
    fun create(
        caller: CurrentUser,
        @Valid @RequestBody request: CreateBondRequest,
    ): ResponseEntity<BondResponse> {
        val view = createBond.create(request.toDraft(UserId(caller.id)))
        return ResponseEntity.status(HttpStatus.CREATED).eTag(BondResponse.etagOf(view)).body(BondResponse.from(view))
    }

    @GetMapping
    fun list(caller: CurrentUser): BondsResponse = BondsResponse(listBonds.forUser(UserId(caller.id)).map(BondResponse::from))

    @GetMapping("/{bondId}")
    fun get(
        caller: CurrentUser,
        @PathVariable bondId: String,
    ): ResponseEntity<BondResponse> {
        val membership = guard.membershipOf(UserId(caller.id), bondIdOrNotFound(bondId))
        val view = getBond.view(membership)
        return ResponseEntity.ok().eTag(BondResponse.etagOf(view)).body(BondResponse.from(view))
    }

    private fun bondIdOrNotFound(raw: String): BondId = BondId(runCatching { UUID.fromString(raw) }.getOrElse { throw BondNotFoundException() })
```
